# Netai in Claude, from a phone (#5743, the founder's D823)

One page for the 21 October guests. Only a phone is needed. About 3 minutes.

## ქართულად — Claude

1. ტელეფონის ბრაუზერში (Safari / Chrome) გახსენი **claude.ai** და შედი შენი ანგარიშით.
   Claude-ის აპლიკაციაში კონექტორის დამატება არ შეიძლება — მხოლოდ ბრაუზერში.
2. მენიუ (☰) → **Customize** → **Connectors**.
3. **Add custom connector**.
4. Name: **Netai** · URL: **https://api.netai.guru/mcp** → **Add**.
5. **Connect** → გაიხსნება Netai-ს გვერდი: ჩაწერე შენი ნომერი, მოვა კოდი, ჩაწერე.
6. მზადაა. ახლა Claude-ის აპლიკაციაშიც ჩანს (ავტომატურად გადადის).
7. კონტაქტებისთვის ჩატში დაწერე: „ჩემი კონტაქტები Netai-ში ჩავტვირთო" — Claude მოგცემს ერთჯერად ბმულს;
   გახსენი, აირჩიე კონტაქტების ფაილი (.vcf), დააჭირე ატვირთვას.

უფასო Claude-ზე ერთი საკუთარი კონექტორის დამატებაა შესაძლებელი — Netai ის ერთი იქნება.

## English — Claude

1. In the phone's browser (Safari / Chrome) open **claude.ai** and sign in.
   The Claude app cannot add a connector; the browser can.
2. Menu (☰) → **Customize** → **Connectors** (claude.ai moved them from Settings).
3. **Add custom connector**.
4. Name **Netai**, URL **https://api.netai.guru/mcp** → **Add**.
5. **Connect** → Netai's page opens: your number, then the code you receive.
6. Done. It appears in the Claude app on its own.
7. For contacts, write in the chat: "put my contacts into Netai" — Claude gives a one-time
   link; open it, pick the contacts file (.vcf), tap Upload.

A free Claude plan allows one custom connector.

## ChatGPT

Adding a custom connector to ChatGPT is done on the web (chatgpt.com in the phone's
browser) under Settings → Apps / Connectors with Developer mode, and which plans may do it
(Free, Plus, Pro, Business) has changed during 2026 and is reported differently by different
sources. Until OpenAI's own help page or a test on a Plus account says otherwise, plan the
event as: **Claude works for everyone; ChatGPT is a bonus for those whose plan allows it.**
A listed app in ChatGPT's app directory would work on every plan — that needs Netai's
submission to OpenAI (see below).

## Old "Ally" connectors

Anyone who added the connector before 18 October has it saved as **Ally** at
`https://api.allyapp.one/mcp`. It still works (the same server answers there), but its name
stays "Ally" until the person renames it, or removes it and adds Netai as above.

## The directories (so a guest can just tap "Connect")

- **Claude connectors directory**: submitted by the company (Anthropic's directory form),
  with the server URL, a description, the icon (https://api.netai.guru/assets/netai-icon-256.png),
  privacy policy (https://www.netai.guru/privacy) and a test account.
- **ChatGPT apps directory**: submitted by the company through OpenAI's developer platform,
  same material; it goes through OpenAI's review.

Both are submissions in the company's name — the founder or Misho sends them; the server side
(URL, OAuth, icon, tool texts) is ready.
